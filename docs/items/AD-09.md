# AD-09: `ParsedDocument.pages` tuple type enforced at runtime

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Adapters, AD-07 row
residual "`pages` tuple type not enforced at runtime").

- Target references: ARCHITECTURE.md §4 (Parse & chunk); `docs/items/AD-07.md`; D-003 (no domain
  words).
- Objective: `ParsedDocument(pages=...)` raises `ParseError` when `pages` is not a `tuple` (a list,
  generator or other iterable), so the frozen record cannot hold a mutable or one-shot sequence;
  tuples (including `()`) behave as before.

  are not coerced to tuples.
