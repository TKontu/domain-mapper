# AT-02: manual attribute set/list CLI

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §2 (Attribute), §4 stage 8 (Quantitative attributes), §5
  (`attribute_value`); `core/attribute_store.py` (AT-01); `core/scope_pack.py` (`Attribute`);
  `core/cli.py` (`run_assessments` load/engine/error pattern); D-003 (neutral fixtures only,
  `scopes/_example`).
- Objective: `landscape attribute-set --scope S --entity ID --attribute ATTR_ID --value TEXT`
  parses TEXT per the pack attribute's type (int, float, enum, bool `true`/`false`, ISO date),
  calls `record_attribute_value`, commits and prints `attribute_value <id> entity <ID> attribute
  <ATTR_ID>`; `landscape attributes --scope S --entity ID` prints `<attr_id> <value json> <unit
  or ->` per current value sorted by attribute id, or `no attributes` (exit 0).
- Errors: an attribute id not in the pack's attributes.yaml, an unparsable value or a value
  failing validation exits 2 with one `error:` line and writes nothing; a database error uses
  `_exit_database_unavailable`.
- Scope / non-goals: manual set/list only (run_id None). No LLM extraction, evidence linkage,
  export, unknown-entity check, or change to `core/attribute_store.py`. Files: `core/cli.py`,
  `tests/test_cli_attributes.py`, this file and the AT-02 `todo.md` row.
- Connections / scale: the two commands are the first production callers of
  `record_attribute_value` and `current_attribute_values`. One entity per call; no full-table
  loads. The listed unit is the current pack attribute's (`-` if absent or no longer in the pack).
- Acceptance: offline pytest failing at base, passing at head — set then list round-trips int,
  enum (example pack) and float, bool, date (test-local pack copy); unknown attribute, bad values
  and enum outside values exit 2 with no row; latest set wins; empty entity prints
  `no attributes`. Full gate green.
- Evidence / residuals: assignment 76/A1; the PR body carries the head SHA and gate counts.
  Residuals: SQLite only, PostgreSQL path unexercised; no extraction or evidence linkage yet.
