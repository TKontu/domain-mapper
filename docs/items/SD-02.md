# SD-02: current assessments made stale by a snapshot diff

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 Crawl & snapshot ("Re-crawl": only changed snapshots
  (hash) trigger re-assessment); D-003 (neutral wording).
- Objective: read-only `core.snapshot_diff.stale_assessments(engine, entity_id, base_run_id=None,
  head_run_id=None)` runs `diff_entity_runs` and returns the entity's current assessments with at
  least one evidence URL classified `changed` or `removed`, each with its triggering URLs and
  statuses. `landscape reassess-plan --entity ID [--base-run R] [--head-run R]` prints
  `<criterion_id>\t<rubric_version>\t<assessment_id>\t<status>:<url>[,...]` per stale assessment
  (sorted by criterion, then rubric version) and `total stale N current M`; exit 0. Also fixes the
  SD-01 nits: equal base/head runs exit 2 with "base and head run are the same"; `--base-run`
  alone at the entity's newest run exits 2 ("no run newer than base run R ...") instead of
  diffing in reverse. Both apply to `snapshot-diff` and `reassess-plan`.
- Scope / non-goals: core function, CLI subcommand, offline SQLite tests. No re-assessment
  execution, no writes, no schema change, no content diff, no live crawl, no change to
  assessment_store semantics. Assessments without URL-bearing evidence count only in `current`.
- Acceptance: `tests/test_snapshot_diff.py` and `tests/test_cli_reassess_plan.py` cover changed
  and removed URLs making an assessment stale, unchanged and added not, an assessment cited at
  several URLs listed once with all triggering URLs, evidence without a URL ignored, other
  entities ignored, both nit errors (core and CLI, exit 2), DB error convention; gate green.
- Evidence / residuals: PR (assignment 199/A1). Residuals: evidence URL is the snapshot
  `final_url` while the diff keys on the snapshot `url`, so a redirected page matches only if
  both are equal; not yet run against a real database with two crawl runs of one entity;
  executing re-assessment from the plan is a later SD row.
