# AS-02: Keyword-only evidence retrieval for one entity × criterion

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 stage 7 (retrieval for a criterion: hybrid BM25 on
  `retrieval_hints` + vector on question → top-k → reranker → top-n chunks per entity ×
  criterion); `core/keyword_search.py` (`search_chunks`, IX-03); `core/chunk_store.py`
  (`ChunkRow`); `core/assess.py` (`extract_criterion` chunk shape, AS-01); `core/scope_pack.py`
  (`Criterion.retrieval_hints`, `question`); D-003 (neutral fixtures only).
- Objective: `core/retrieve.py` exposes `build_query(criterion)` and
  `retrieve_evidence(engine, criterion, *, entity_id, n=6, k=24) -> list[tuple[int, str]]`.
  Query rule: `retrieval_hints` in declared order followed by `question`, joined with single
  spaces. It calls `search_chunks(engine, query, limit=k, entity_id=entity_id)`, keeps the
  first `n` hits in hit (score) order, loads their texts in one query and returns
  `(chunk_id, text)` pairs in score order. `n < 1` or `k < n` raises `ValueError`; no hits → `[]`.
- Scope / non-goals: `core/retrieve.py`, `tests/test_retrieve.py`, this file, its `todo.md` row.
  No embeddings/vector search, reranker, CLI, persistence or LLM calls; no change to
  `core/keyword_search.py`, `core/assess.py` or other modules.
- Seam: keyword leg only. The vector leg on `question` and the reranker (follow-up: Assess
  hybrid retrieval + reranker row) slot between the search and the top-`n` cut; `k` is the
  candidate pool kept for them.
- Connections: `retrieve_evidence` and `build_query` are unwired by design; the production
  caller is the later `landscape assess` CLI row.
- Scale: inherits the O(entity corpus) scan of `search_chunks` (IX-03 residual); the text load
  is one query for at most `n` ids.
- Acceptance: offline pytest (tests/test_retrieve.py, SQLite) covering the entity filter, `n`
  cap and score order with stored texts, hint-only and question-only matches, no-match `[]`,
  argument validation, and output fed unchanged into `extract_criterion` with a fake `LLM`.
  Behaviour is seen only when the Assess stage runs over a real stored corpus.
- Evidence / residuals: PR for assignment 61/A1 (see todo row). Residuals: keyword-only (no
  vector leg, no reranker); question words such as stopwords contribute to BM25 (no stopword
  list in `tokenize`); never exercised against a real corpus.
