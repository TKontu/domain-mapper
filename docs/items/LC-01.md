# LC-01: lane cleanup frees finished lanes' worktrees

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: operator ruling 2026-11-27 (round 166; earlier sent as "CL-01", which clashed with the crawl item CL-01 and was never planned); model `/work/iknosreview/scripts/agent_lane_lifecycle.py` (INT-150); scripts/lanes.py `cleanup`.
- Objective: `lanes.py cleanup --go` removes the worktree of every *recorded* lane whose PR is MERGED/CLOSED (or has no PR and is recorded), instead of holding it. Observed round 166: 9 worktrees held (5 `detached`, 4 `dirty` on only an untracked lane `run.sh`), 13 worktrees total.
- Rules to port from the model: (1) disposable paths: lane launcher scripts (`run.sh`, `*_runner.sh`), caches (`.venv`, `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`) and main-checkout copies (`.env`, `HANDOFF.md`, `.claude/settings.local.json`) do not make a tree `dirty`; (2) a detached tree whose lane record is `recorded` and whose HEAD is reachable from origin/main or a remote branch is removable; (3) anything uncertain is still held and reported (real uncommitted files, unpushed commits, `busy`, foreign checkout); (4) a lane whose HANDOFF "carried" line names a recorded lane no longer holds it once it is recorded.
- Scope / non-goals: scripts/lanes.py and its tests only; no venv/DB removal (no lane DBs here); never touches running lanes; no Herdr workspace changes.
- Acceptance: unit tests with seams for each rule (dirty-only-disposable removed, real dirty held, detached recorded removed, detached unpushed held, running lane untouched); full gate green; then a live `lanes.py cleanup --go` on this host drops the held pg156..pg165 trees (seen run).
- Evidence / residuals: round 167/A1 (offline): rules (1)-(4) ported into `scripts/lanes.py` (`disposable`, `_dirty`, `_unpushed`, `_tree_hold(recorded=...)`, recorded lanes skip the carried hold); unit tests in `tests/test_lanes.py` for each acceptance case.
