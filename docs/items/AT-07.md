# AT-07: `landscape attributes-extract` CLI

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 stage 8 (content attributes via structured extraction),
  §5 (`attribute_value`, `evidence`), §6 LLM routing (local extractor); AGENTS.md "Connections",
  "Scale"; D-003 (neutral fixtures only, `scopes/_example`). Follows AT-06.
- Objective: `landscape attributes-extract --scope S --entity ID --attribute A [--n 6]
  [--dry-run]` (`core.cli.run_attributes_extract`). Loads the pack and looks up the attribute
  (unknown id exits 2, no run row); `--n < 1` exits 2. Opens an `attributes_extract` run,
  retrieves up to `--n` of the entity's chunks with BM25 `core.keyword_search.search_chunks` on
  `core.attribute_extract.attribute_query(attribute)` (label, plus enum values), calls
  `extract_attribute` with the `_make_assess_llm` extractor and `store_attribute_extraction` in
  one committed transaction. Prints `value <json|null> checks pass|fail chunks N`, one
  `quote chunk C grounded|ungrounded "..."` line per quote, one `failure ...` line per failed
  check and `attribute_value ID|-`. Exit 0 when checks pass (including null), 1 on failed checks
  (run `finished`, nothing written) or `AttributeExtractError`/`LlmError` (run `failed`), 2 on bad
  input/setup. `--dry-run` prints the plan and writes nothing.
- Scope / non-goals: one entity × one attribute per invocation, BM25 only. No hybrid/embedding or
  rerank retrieval, batch over entities, verifier pass, export changes, migrations or live model
  calls. Files: `core/cli.py`, `core/attribute_extract.py` (`attribute_query` only),
  `tests/test_cli_attributes_extract.py`, this file and the AT-07 `todo.md` row.
- Connections / scale: `run_attributes_extract` is the production caller of `extract_attribute`,
  `store_attribute_extraction` and `attribute_query`; the CLI command is the entry point. One
  LLM call per invocation; input bounded by `--n` chunks and `max_chars`; one transaction.
- Acceptance: `tests/test_cli_attributes_extract.py` (offline SQLite, fake LLM) fails at base and
  passes at head: grounded value stored with linked evidence; ungrounded quote exits 1 with no
  write and run `finished`; null value exits 0 without write; unknown attribute exits 2 with no
  run; entity without chunks makes no LLM call; `LlmError` exits 1 with run `failed`;
  `attribute_query` covers enum values. Full gate green.
- Residuals: SQLite only (PostgreSQL unexercised), no live model, BM25 only, single entity per call.
