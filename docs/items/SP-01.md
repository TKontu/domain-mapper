# SP-01: Scope pack Pydantic models

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Scope pack schema).

- Target references: ARCHITECTURE.md §2, §3 (3.1, 3.2), §10, §11 (Pydantic for scope packs); D-003.
- Objective: `core/scope_pack.py` exposes Pydantic v2 models (extra keys forbidden) for every scope-pack file and `load_scope_pack(path) -> ScopePack`. `scope.yaml` and `rubric.yaml` are required; `vocabulary`/`sources`/`attributes`/`profiles`/`views` YAML are optional (absent = empty defaults). Failures raise `ScopePackError` naming the file and field.
- Cross-file checks: ids unique per kind; criterion `applies_to`, topic `segments` (segment-specific topics), vocabulary and attribute segment references must be declared segments; criterion `statuses` keys must be `status_scale` ids.
- Scope: `core/scope_pack.py`, `tests/test_scope_pack.py`, `pydantic` + `pyyaml` deps (`types-pyyaml` dev). Non-goals: `landscape validate`, JSON Schema export, completing `scopes/_example/`, DB work.
- Design note: optional-file shapes (`entries`, `sources`, `attributes`, `profiles`, `views` lists) are first-pass shapes and are not yet given in ARCHITECTURE.md. Completing `scopes/_example/` will test them.
- Connections: unwired by design; production caller is the `landscape validate` row.
- Evidence / residuals: PR #10 merged (head 64e241a), round 4. Seen: `load_scope_pack('scopes/_example')` on main dc3ae93 (2 segments, 3 layers, 2 topics). Residuals: `Source.role` is single-valued while ARCHITECTURE §5 lists plural roles; optional-file shapes unproven.
