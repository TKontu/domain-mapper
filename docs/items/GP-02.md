# GP-02: genericity check covers app/ as well as core/

Status and dependencies live in the canonical backlog, not duplicated here.

- Origin: GP-01 residual "scans core/ only (not app/)" (todo.md Phase 5).
- Target references: ARCHITECTURE.md §10 (genericity contract); D-003; GP-01.
- Objective: `tests/test_core_genericity.py` scans `app/**/*.py` in addition to `core/**/*.py`
  with the same `_example` term set, allowlist ratchet (unlisted and stale both fail) and log.
  Each new hit gets an allowlist row with verdict and reason and a matching row in
  `docs/genericity-log.md`.
- Premises: (1) app/ is Python under `app/` (`ls app`); (2) a planner pre-scan found one app/ hit,
  `app/cli.py` -> `terms` (generic word).
- Acceptance: (a) test passes at head and its negative case shows an `_example` term added to a
  tmp `app/` file fails; (b) allowlist and log agree entry for entry; (c) no changes to `core/`,
  `app/`, `scopes/`, schema, ARCHITECTURE.md or decisions; (d) gate
  `uv run pytest -q && uv run ruff check . && uv run ruff format --check tests && uv run mypy core app` green.
- Non-goals: refactoring leaks; scanning scripts/ or private scopes; live runs.
- Connections / scale: no new public symbol; test + fixture + doc only; bounded by source size.
