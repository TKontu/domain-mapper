# AT-03: attributes JSON Lines export

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §2 (Attribute), §5 (`attribute_value`), §6 exports (JSON of
  attributes); `core/attribute_store.py` (`current_attribute_values`, AT-01);
  `core/entity_store.py` (`iter_entities`); `core/cli.py` (`run_scores_export` atomic-write/error
  pattern); D-003 (neutral fixtures only, `scopes/_example`).
- Objective: `landscape attributes-export --scope S --out PATH` streams the entities of the
  scope's id in ascending id via `iter_entities`; for each it calls
  `current_attribute_values(session, entity.id)` and, when that is non-empty, writes one JSON
  Lines object `{"entity_id": ID, "attributes": {attr_id: value, ...}}` with the attribute ids
  sorted and each value as its stored JSON-decoded form. Entities without values are skipped and
  counted. Lines go to `<out>.tmp`, renamed to `out` with `os.replace` on success, so a failure
  leaves no `PATH`; the command prints
  `exported N entities to PATH (skipped M without attributes)`.
- Errors: a missing or invalid scope pack, an unwritable output directory or a database error
  exits 2 with one `error:` line (`_exit_database_unavailable` for the database); a failure
  mid-stream leaves neither `PATH` nor `PATH.tmp`.
- Scope / non-goals: export only. No change to `core/attribute_store.py`, no units, no evidence,
  no extraction, no change to other commands. Files: `core/cli.py`,
  `tests/test_cli_attributes_export.py`, this file and the AT-03 `todo.md` row.
- Connections / scale: `run_attributes_export`'s production caller is the `attributes-export`
  command; its consumer is the later static-site row. One entity's values are held in memory at a
  time (one query per entity, N+1), and `iter_entities` pages the entity rows.
- Acceptance: offline pytest failing at base, passing at head — two entities with values and one
  without yield two lines and `skipped 1`, the latest value per attribute wins, attribute ids are
  sorted and values are JSON-decoded; an empty database yields an empty file and `exported 0`; an
  unwritable output directory exits 2 and leaves neither the file nor a `.tmp`. Full gate green.
- Evidence / residuals: assignment 77/A1; the PR body carries the head SHA and gate counts.
  Residuals: SQLite only, the PostgreSQL path is unexercised; one query per entity (N+1); the
  export carries no unit or evidence, only the stored values.
