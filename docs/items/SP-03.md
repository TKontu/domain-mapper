# SP-03: JSON Schema export for editor autocompletion

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Scope pack schema).

- Target references: ARCHITECTURE.md §3; D-003; docs/items/SP-01.md, docs/items/SP-02.md.
- Objective: `landscape schema --out DIR` writes one JSON Schema (draft 2020-12, from pydantic `model_json_schema`) per scope-pack YAML file that `load_scope_pack` reads, named `<file stem>.schema.json`, and prints the written paths. Without `--out` it prints the schema of the file named by `--file NAME` (default `scope.yaml`) to stdout; an unknown `--file` exits 2 with a message.
- Scope: `scope_pack_json_schemas()` and the `_FILE_MODELS` file→model map in `core/scope_pack.py`, `schema` subcommand in `core/cli.py`, tests in `tests/test_scope_pack.py` and `tests/test_cli.py`, this file. Non-goals: model field/validation changes, committed generated schemas, editor config.
- Connections: `landscape schema` is the production caller of `scope_pack_json_schemas`.
- Scale: N/A (seven small static schemas).
- Evidence / residuals: round 6, PR #16 merged (head 7926504); assignment A1. Seen: `uv run landscape schema --out <tmp>` lists seven files (scope, rubric, vocabulary, sources, attributes, profiles, views `.schema.json`), exit 0; `--file x` exits 2. Residuals: `jsonschema` is not installed, so the example-pack check compares top-level keys and `required` against the models and asserts `additionalProperties: false` on every object definition, not full schema validation; no editor wiring (e.g. YAML language-server modelines) is provided.
