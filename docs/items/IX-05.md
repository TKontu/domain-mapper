# IX-05: `index` run row closes `failed` on unexpected errors

Status and dependencies live in the canonical backlog (`todo.md`, Phase 1 › Index).

- Target references: ARCHITECTURE.md §6 Index; IX-02 (`docs/items/IX-02.md`, its open-run residual); D-003.
- Objective: in `core/cli.py` `run_index`, every failure after the `index` run row opens closes it `failed` with `finished_at` set before propagating. `EmbeddingError`/`EmbedStoreError` keep their `error <ErrorName>: <message>` stderr line and exit 1; an unexpected `Exception` (e.g. `RuntimeError` from the embedder) or `KeyboardInterrupt` closes the run `failed` and propagates.
