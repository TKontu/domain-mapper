# EV-02: eval-harness CLI + gold-set loader wiring EV-01 metrics

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §7 (gold set in the scope pack's `gold/`; metrics per
  criterion), §3.2 status ids; D-003 (neutral fixtures only: `scopes/_example`, tmp_path).
- Objective: `landscape eval --scope S [--rubric-version V] [--gold FILE]` loads a gold set,
  pairs each label with the current assessment of the same (entity, criterion) and prints
  `core.eval_metrics.compute_metrics` rows: `unmatched N`, one line per criterion (sorted), then
  `overall`, each with n, accuracy, kappa, silent_rate, false_strong_rate (`-` for None).
- Gold format (engine choice): JSON Lines at `<scope>/gold/labels.jsonl` by default, one object
  per line `{"primary_domain": str, "criterion_id": str, "status": str}`. Blank lines skipped. A
  malformed line, a missing/non-string key, a status outside the rubric status scale, or a
  duplicate (primary_domain, criterion_id) raises `GoldSetError` naming the line number, never the
  content. Streamed line by line (`core/gold_set.py`). Entities resolve by (scope id,
  primary_domain). The top status for false-strong is the highest-valued status in the scale.
- Scope / non-goals: loader, CLI subcommand, tests. Non-goals: the expert-labelled real gold set
  (H), thresholds.yaml, release gate, rubric/architecture/schema changes, live model.
- Acceptance: unmatched labels counted and excluded (never auto-labelled); missing gold file or
  `GoldSetError` → stderr, exit 2; empty match set → n=0 lines, exit 0; `--rubric-version`
  passes through to `iter_current_assessments`; local gate green. Memory: dicts keyed by gold
  labels only (bounded, ~30 entities × criteria); entities and assessments read in batches.
- Evidence / residuals: PR for round 188/A1. Residual: no expert-labelled gold set exists yet
  (H); the harness has only run on tmp_path fixtures. Without `--rubric-version`, when several
  rubric versions are current for one pair, the newest assessment is used.
