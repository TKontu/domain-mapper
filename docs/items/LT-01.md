# LT-01: `round.py resolve --waive` records a reviewed waiver for non-passed checks

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Repo & infra, workflow tooling).

- Target references: SPEC.md "Mechanical scaffolding" (`resolve` checks the submitted head, reported
  check statuses and local merge commit existence) and "Reconciliation is the completion gate"
  (failures are recorded; failed required gates keep the round open); `.agent/commands/merge-round.md`
  (merged resolution); standing operator ruling: pre-existing failures are waived citing the ruling
  (as used in `docs/items/CR-01.md`). No architecture or decision change.
- Objective: `resolve ROUND A --outcome merged ... --waive REASON` records non-passed checks as
  waived instead of refusing ("Not all checks passed"); without `--waive` resolution is unchanged.
- Scope / non-goals: `scripts/round.py`, `tests/test_round.py`, this file, its `todo.md` row and one
  sentence in `.agent/commands/merge-round.md`. Non-goals: result schema, `scripts/merge_guard.py`,
  the supervisor.
- Acceptance: (a) failed check + `--waive` → merged, with `waived.reason` and the non-passed
  checks' `command`/`status`; (b) failed check without `--waive` → still refused; (c) blank or
  whitespace reason, `--outcome cancelled`, or all checks passed + `--waive` → refused with the
  assignment unchanged; (d) a round whose assignment was waived closes; (e) `status` prints the
  waiver. Head match, packet binding, candidate identity and merge-SHA checks still apply. Offline:
  `uv run pytest -q && uv run ruff check . && uv run ruff format --check core adapters tests &&
  uv run mypy core`.
- Evidence / residuals: PR #144 (assignment 62/A2, base `4643d7f`, branch
  `task/lt-01-resolve-waive`; the PR carries the revision-bound head and gate output). Tests were
  written first: at base `4643d7f` with the new tests, `uv run pytest -q tests/test_round.py -k
  waive` → 9 failed, 2 passed, 30 deselected. At the head: `uv run pytest -q` → 1168 passed, 5
  skipped, 158 subtests passed (the 5 skips are `DM_TEST_DATABASE_URL` guards; the PostgreSQL path
  is not exercised); `uv run ruff check .` → All checks passed; `uv run ruff format --check core
  adapters tests` → 92 files already formatted; `uv run mypy core` → Success, no issues in 24
  source files. The new tests passed five consecutive runs. Residuals: a waiver is a recorded
  claim, not proof — the reviewer still owns citing the ruling and judging the failure pre-existing;
  result schema and check collection are unchanged. Stays partial (merged-pending) until the PR
  merges and a real merged resolution with `--waive` is seen.
