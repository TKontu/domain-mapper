# CR-15: `snapshot` rows carry the `crawl` run id of their invocation

Status and dependencies live in the canonical backlog (`todo.md`, Phase 1 › Crawl).

- Target references: ARCHITECTURE.md provenance (every stage records a `run`); `core/screen_store.py` (`run_id` FK pattern); `core/snapshot_store.py` (`record_snapshot`); `docs/items/CR-14.md`; D-003 (neutral fixtures only).
- Objective: every `snapshot` row written by `landscape crawl` (URL mode via `_crawl_urls`/`_crawl_targets` and entity mode via `_crawl_entities`) carries the id of that invocation's `crawl` run row. `SnapshotRow.run_id` is nullable, indexed and an FK to `run.id`; `record_snapshot` and `ingest_page` take a keyword `run_id: int | None = None` and store it; `_Crawler` passes the open run's id to `ingest_page` (the run row opens before the crawler is constructed). Other callers keep `run_id=None`; a missing `FIRECRAWL_URL` still exits 2 with no run row (the fetcher is built before the run opens in both modes).
- Scope / non-goals: `core/snapshot_store.py`, `core/ingest.py`, `core/cli.py` (crawl paths only), `tests/test_snapshot_store.py`, `tests/test_ingest.py`, `tests/test_cli_crawl.py`, `tests/test_cli_crawl_entities.py`, this file and its `todo.md` row. Non-goals: migrations/ALTER for existing databases (there is no migration tool yet: record as residual that a database created before this change lacks the column), chunk `run_id`, other stages, live crawl.
- Acceptance: TDD — `record_snapshot(..., run_id=R)` round-trips R and defaults to `None`; `ingest_page(..., run_id=R)` stores R on the snapshot; a URL crawl and an entity crawl each leave every snapshot with `run_id` equal to the single `crawl` run row's id; two crawl invocations give disjoint run ids. Local gate `uv run pytest -q && uv run ruff check . && uv run ruff format --check core adapters tests && uv run mypy core` (offline, SQLite, loopback fake Firecrawl).
