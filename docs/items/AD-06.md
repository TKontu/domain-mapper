# AD-06: `Fetcher` adapter interface

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Adapters, row
"`Fetcher` adapter around own web scraping tool").

- Target references: ARCHITECTURE.md §4 (Crawl & snapshot: `fetch(url, *, render_js=False) ->
  FetchResult`), §10 (genericity contract); D-003 (no domain words); `adapters/search.py`
  (Protocol + frozen-dataclass house style). Raw storage is an open (D) decision; nothing is stored.
- Objective: `adapters/fetcher.py` defines a `runtime_checkable` `Fetcher` protocol; frozen
  `FetchResult(final_url, status, content_type, body_bytes, headers, fetched_at)` with a `sha256`
  property (hex digest of `body_bytes`); `FetchError` (a `ValueError`); and `InMemoryFetcher`, a fake.
- Semantics: headers are copied into a read-only `MappingProxyType`. The fake rejects non-http(s)
  or hostless URLs, raises `FetchError` for unknown URLs, follows one configured redirect hop
  (result `final_url` is the target's), and raises `FetchError` when the body exceeds `max_bytes`
  (must be a positive int). `render_js` is accepted, does not change the result, and is recorded
  in `calls` as `(url, render_js)`.
- Scope: `adapters/fetcher.py`, `tests/test_fetcher_adapter.py`, `docs/items/AD-06.md`.
- Non-goals: wrapping the real scraping tool, network calls, robots.txt, rate limiting, storage,
  DB tables, stage wiring, dependency changes.
- Acceptance: tests written first, failed with `ModuleNotFoundError: No module named
  'adapters.fetcher'`. They show conformance (isinstance; mypy via `_conforms()`), exact contract
  fields, unknown URL, non-http(s) rejection, redirect hop, body bound, `render_js` recording,
  frozen record, immutable headers copy and stable `sha256`.
- Scale / memory bound: body at most `max_bytes` (default `DEFAULT_MAX_BYTES` = 10 MiB). A real
  implementation must stream the response and stop reading at the cap, not download then check.
- Connections: **unwired by design**. First production caller: the Phase 1 Crawl & snapshot row.
- Evidence / residuals: round 13, branch `task/ad-06-fetcher-adapter`, base 57ba142. Gate offline:
  `uv run pytest` → 364 passed, 3 skipped (pre-existing, `DM_TEST_DATABASE_URL` unset);
  `uv run ruff check .` → passed; `uv run ruff format --check adapters tests` → passed;
  `uv run mypy core adapters` → no issues in 14 files. Residuals: no real fetcher; no retry,
  robots.txt, rate limiting, per-host concurrency, multi-hop redirects or raw storage; result
  shape to check against the real scraping tool.
