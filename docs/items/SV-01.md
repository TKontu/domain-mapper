# SV-01: a frozen main backs the round supervisor off instead of halting it

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: `.agent/supervisor.md` (no-endless-wait bound); `.agent/commands/reconcile.md`
  Progress review (a stall is never a reason to halt); `scripts/round_supervisor.py` `after_round`,
  `Config`, `Tracker`, `Supervisor.finish_round`. Operator instruction 2026-11-26.
- Objective: `no_advance >= max_no_advance` returns a `backoff` action, not `halt`. The k-th stalled
  round past the threshold (k = 0, 1, ...) waits `min(backoff_base_s * 2**k, backoff_max_s)`
  (defaults 10 min, 4 h) before the next round and writes one `watchdog` dashboard note
  "main unchanged across N rounds; backing off M min". An advancing round resets it. The wait is
  interruptible by `STOP`; `max_recycles` still halts.
- Scope / non-goals: `scripts/round_supervisor.py`, its tests, `.agent/supervisor.md`. Not other
  watchdog thresholds, `lanes.py`, `round.py`.
- Acceptance: TDD in `tests/test_round_supervisor.py` (backoff at threshold, escalation and cap,
  reset on advance, one note per backoff, recycle halt unchanged, loop waits with a fake clock,
  STOP interrupts); full offline gate green.
