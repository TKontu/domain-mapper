# EV-01: per-criterion eval metrics module

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §7 (metrics per criterion), §3.2 (status scale ids incl.
  `strong`, `silent`, `na`); D-003 (neutral fixtures only).
- Objective: pure `core/eval_metrics.py` computes per criterion, from paired (auto, human) status
  labels, n, accuracy, unweighted Cohen's κ, silent-rate and false-"strong" rate (top status is a
  parameter, default `strong`), plus an overall row.
- Scope / non-goals: module and tests, this file, todo sub-bullet. Non-goals: gold-set loading, CLI,
  thresholds.yaml, release gate, DB access, rubric/architecture changes, live model. Public symbols
  are unwired by design; the eval-harness CLI / gold-set loader (future EV-02) wires them.
- Acceptance: κ matches hand values (perfect → 1.0; textbook 2x2 → 0.4); κ = 1.0 when expected and
  observed agreement are both 1 (single class); empty input → n=0 and None metrics; silent and
  false-strong rates match hand values; rows grouped per criterion, sorted, overall last; input
  consumed once with O(criteria × statuses) memory. Gate:
  `uv run pytest -q && uv run ruff check . && uv run mypy core app`, offline.
- Evidence / residuals: PR for assignment 187/A1. Residual: wiring (EV-02).
