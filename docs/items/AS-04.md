# AS-04: Assess local verifier call plus routing (one entity × criterion)

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 stage 7 (Verifier: local, different model → agree/disagree
  + reason; agree & checks pass → accept high; disagree / check fail → cloud adjudication; no
  relevant evidence → silent), §6 routing (verifier is a different model family), untrusted
  evidence rule; D-003 (neutral fixtures only); extractor `core/assess.py` (AS-01).
- Objective: `core/verify.py` exposes `verify_extraction(llm, rubric, criterion, chunks,
  extraction, *, run_id, max_chars=12000) -> Verification | None` and `route(extraction,
  verification | None) -> Route`. The prompt holds the criterion question, status definitions,
  the extractor's status + quotes + rationale and the same delimited, neutralised, truncated
  evidence block as AS-01; schema `{agree: bool, reason: str}`; call purpose `assess_verify`.
  Malformed output (not an object, non-boolean/missing `agree`, missing/blank `reason`) raises
  `AssessError` naming the field only. A `silent` extraction makes no call and routes `silent`.
  `Route.kind` is `accept` (confidence `high`; agree and checks passed) or `adjudicate` (disagree
  or checks failed, with reason) or `silent`.
- Scope / non-goals: `core/verify.py`, `tests/test_verify.py`, this file, its `todo.md` row. No CLI
  wiring, cloud adjudication, persistence, live model calls; no change to `extract_criterion` or
  `core/grounding.py`.
- Connections: `verify_extraction`, `route`, `Verification`, `Route` are unwired by design; the
  production caller is the later row wiring the verifier into `landscape assess` (AS-03 command).
- Scale: one verifier call per non-silent entity × criterion; evidence capped by `max_chars`.
- Acceptance: offline pytest with a fake `LLM` (tests/test_verify.py), failing at base (module
  absent), passing at head; behaviour is seen only when run against a real local verifier model.
- Evidence / residuals: PR for assignment 63/A2 (base 563825e). Residuals: reuses AS-01 private
  helpers (`_neutralise`, `_truncate`, `_scale_ids`); routing a non-silent extraction without a
  verification raises `ValueError`; checks-failed routes to adjudication even when the verifier
  agrees; never exercised against a live model; choice of a different model family is the caller's
  configuration.
