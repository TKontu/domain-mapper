# AG-04: scores export as JSON Lines

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §10 Aggregate & score (score and coverage always shown
  together); AG-02/AG-03 (`core/cli.py` `run_scores`); AS-12 (`run_export`, tmp-file + rename
  pattern); D-003 (neutral fixtures only, `scopes/_example`).
- Objective: `landscape scores-export --scope S --out PATH` writes one JSON Lines object per
  scored entity of the scope to PATH, each with exactly the AG-03 JSON shape
  `{"entity_id", "segments", "rubric_version", "topics": [...]}` (topics in rubric order,
  `score`/`coverage` unrounded or `null`), entities in ascending id, then prints
  `exported N entities to PATH (skipped M without screen result)`.
- Scope / non-goals: segments from each entity's latest screen result; entities without one are
  skipped and counted. Assessments are the current ones at the pack's version, as in
  `run_scores`. The per-entity object builder is shared with `scores --format json` (AG-03 output
  byte-identical). Files: `core/cli.py`, `tests/test_cli_scores_export.py`, this file and the
  AG-04 `todo.md` row. No weights, silent penalty, schema change, Parquet/CSV, frontend code, or
  change to `landscape export` / `landscape scores` behaviour.
- Acceptance: offline pytest failing at base and passing at head — two screened entities match
  `scores --format json` per entity; an unscreened entity is skipped and counted; a screened
  entity without assessments has null scores; empty scope writes an empty file; an unwritable
  output directory exits 2 leaving no PATH or PATH.tmp; a mid-stream failure leaves no PATH.
  Full gate green.
- Connections / scale: the `scores-export` command is the caller of `run_scores_export`; output
  is the producer for the later frontend row (unwired consumer by design). Entities streamed via
  `iter_entities` (one page), one entity's assessments at a time, one line written per entity.
- Evidence / residuals: assignment 74/A1. One query set per entity (N+1 queries). Seen offline
  only (SQLite); PostgreSQL path unexercised.
