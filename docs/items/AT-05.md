# AT-05: attribute value evidence

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 (`evidence(id, assessment_id NULL, attribute_value_id
  NULL, chunk_id NULL, ...)`), §2 (an Attribute carries evidence); AGENTS.md "Connections",
  "Scale"; D-003 (neutral fixtures only, `scopes/_example`).
- Objective: `EvidenceRow` (`core/assessment_store.py`) gains a nullable, indexed
  `attribute_value_id` FK to `attribute_value.id`; its `assessment_id` becomes nullable.
  `record_attribute_value(..., evidence=())` accepts `(chunk_id, quote, grounded)` items and
  appends one evidence row each with `attribute_value_id` set and `assessment_id` NULL, in the
  caller's session (flush, no commit). `attribute_evidence_many(session, attribute_value_ids)`
  returns evidence per value id in id order, one query per ≤500 ids, `{}` for empty input with no
  statement.
- Scope / non-goals: schema columns, write path and read helper only. No extraction, CLI, export
  or migration changes; assessment evidence behaviour unchanged. Files: `core/assessment_store.py`,
  `core/attribute_store.py`, `tests/test_attribute_store.py`, this file and the AT-05 `todo.md` row.
- Connections / scale: both functions are unwired by design; the later attribute-extraction row is
  their production caller. Reads batch ≤500 ids per query.
- Acceptance: offline pytest failing at base, passing at head — a value with two evidence items
  yields two rows (`attribute_value_id` set, `assessment_id` NULL) returned in id order; a value
  without evidence has no entry; an invalid value writes neither value nor evidence; empty input
  returns `{}` without a statement; existing assessment evidence tests pass unchanged. Full gate
  green.

  Residuals: SQLite only, PostgreSQL unexercised; unwired.
