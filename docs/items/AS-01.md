# AS-01: Assess extractor call plus deterministic checks (one entity × criterion)

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §3.2 (rubric shape), §4 stage 7 (criterion assessment),
  §6 (LLM routing: extractor is local); pattern `core/screen.py`; grounding `core/grounding.py`
  (GR-01); D-003 (neutral fixtures only).
- Objective: `core/assess.py` exposes `extract_criterion(llm, rubric, criterion, chunks, *,
  run_id, max_chars=12000) -> Extraction`. It builds a JSON schema (status enum = scale ids minus
  `na`; each quote cites one chunk id from the given ids), a prompt holding the criterion
  question, per-status definitions and the chunks inside a delimited evidence block labelled
  untrusted data (delimiter look-alikes in chunk text are neutralised), calls
  `llm.complete(..., purpose="assess_extract", run_id=..., json_schema=...)`, validates strictly
  and runs deterministic checks. Malformed output raises `AssessError` (a `ValueError`; message
  names the field only). Empty `chunks` returns `silent` without a model call. Evidence beyond
  `max_chars` is truncated in chunk order; only the chunks sent are citable.
- Grounding acceptance rule: a quote is grounded only when `ground_and_locate` matches it in its
  cited chunk at tier 1 (method `exact`: lowercase + collapsed whitespace) or tier 2 (method
  `normalised`: additionally punctuation-stripped). Tier 3 (markdown-stripped) and tier 4 (fuzzy)
  count as not grounded. A non-`silent` status needs at least `criterion.evidence_min` grounded
  quotes; failures are recorded in `Extraction.failures` and set `checks_passed` False.
- Scope / non-goals: `core/assess.py`, `tests/test_assess.py`, this file, its `todo.md` row. No
  retrieval, verifier, cloud adjudication, persistence, CLI, inherited group documents or live
  model calls; no change to `core/grounding.py`.
- Connections: `extract_criterion`, `Extraction`, `AssessError` are unwired by design; the
  production caller is the later Assess retrieval + `landscape assess` row.
- Scale: one model call per entity × criterion; total evidence characters capped by `max_chars`.
- Acceptance: offline pytest with a fake `LLM` (tests/test_assess.py); behaviour is seen only
  when the Assess stage runs against a real local extractor.
- Evidence / residuals: PR for assignment 60/A1. Residuals: never exercised against a live
  model; the caller decides `na` from `applies_to`; spans refer to the (possibly truncated) chunk
  text sent to the model.
