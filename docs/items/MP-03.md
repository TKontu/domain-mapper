# MP-03: deterministic market presence extraction

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 data model `market_presence(entity_id, country,
  presence_type, evidence_id)` and the Layer row; MP-01 (`docs/items/MP-01.md`), MP-02
  (`docs/items/MP-02.md`, `record_presence(evidence_id=)`); `core/chunk_store.py`
  (`ChunkRow.snapshot_id`); `core/snapshot_store.py` (`SnapshotRow.entity_id`); D-003 (neutral
  fixtures only, `scopes/_example`); GV-01/GV-02/GV-03 ratchets.
- Objective: presence rows extracted from stored chunks without an LLM. A scope pack may declare
  optional `presence_terms: {CC: [term, ...]}` (CC uppercase alpha-2; terms non-empty strings;
  validated on load). `core/presence_extract.py` compiles one case-insensitive, word-boundary,
  regex-escaped pattern per scope and streams each entity's chunks (chunk.snapshot_id ->
  snapshot.entity_id) in id order; each matched (entity, country) cites the lowest matching chunk.
- CLI: `landscape presence-extract --scope DIR --type TYPE [--entity N ...] [--dry-run]` calls
  `record_presence(..., TYPE, evidence_id=<chunk>)` per match, prints `entity E country CC chunk
  N` lines and `extracted K`; `--dry-run` prints the same and writes nothing. Unknown type, a
  pack without `presence_terms`, or an entity not in the scope exits 2 with one line. Without
  `--entity` all entities of the scope are scanned.
- Scope / non-goals: no LLM, no presence-type inference (caller supplies `--type`), no
  migrations, no Postgres, no mosaic/scores-export or EX-01 changes.
- Connections / scale: `app.cli.run_presence_extract` is the production caller of
  `extract_presence`, `compile_terms` and `Scope.presence_terms`. One streamed query per entity
  (`yield_per`), stopping early once every country is found; one regex per scope.
- Acceptance: offline pytest failing at base, passing at head (`tests/test_presence_extract.py`):
  lowest-chunk evidence; case-insensitive and word-boundary; entity filter; no attribution of
  another entity's chunks; dry-run writes nothing; idempotent rerun; missing `presence_terms` or
  bad type exits 2; invalid country key fails validation; existing packs and MP-01 / MP-02 /
  FE-04 / EX-01 tests unchanged and green. Full gate green.
- Evidence / residuals: assignment 113/A1; the PR body carries the head SHA and gate counts.
  Residuals: no bound on terms count (one alternation regex); literal term matching only (no
  inflection, no ambiguity handling); SQLite only; an existing row's evidence is kept, not moved
  to a lower chunk.
