# XP-03: CSV format for attributes-export

Status and dependencies live in the canonical backlog, not duplicated here.

- Origin: XP-01/XP-02 gave `scores-export` a CSV format; `attributes-export` (AT-03/AT-04/AT-10/
  AT-11) was still JSON Lines only. Additive output format; no decision needed.
- Objective: `landscape attributes-export --scope S --out PATH --format csv` writes one CSV with
  one row per entity that has current attribute values; `--format jsonl` (default) is unchanged.
- Acceptance: (a) header `entity_id` then, per pack attribute in pack order, `<attr_id>.value`,
  `<attr_id>.unit`, `<attr_id>.evidence_count`, `<attr_id>.grounded_count`; header written with
  zero entities. (b) one row per exported entity in ascending id; an attribute without a current
  value gives four empty cells; a current value whose attribute id is not in the pack is dropped
  from CSV (JSON Lines unchanged). (c) cells go through `_csv_cell` (XP-02 formula escaping,
  numbers unchanged, lists joined with `;`). (d) unknown `--format` exits 2 before setup or any
  write; tmp-then-rename atomicity; streaming per `ATTRIBUTES_EXPORT_BATCH`. (e) summary line and
  skipped count unchanged. (f) `--format jsonl` byte-identical to the default. (g) gate green.
- Non-goals: Parquet, evidence quotes in CSV, other export commands.
- Residuals: Parquet not done; not seen over real data; PostgreSQL unexercised.
