# EV-04: gate report from `landscape eval --gate` into the exports

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §7 ("Release gate per layer ... criteria below threshold
  are published as 'experimental' or hidden"); §12 Publish (exports feed the static site);
  D-003 (neutral fixtures only: `scopes/_example`, tmp_path). Builds on EV-03
  (`core/eval_thresholds.py`, `run_eval(..., gate=True)`) and the export (`run_export`,
  `_export_object`, `_export_csv_row`, `EXPORT_CSV_HEADER` in `app/cli.py`).
- Objective: `landscape eval --gate --gate-out FILE` writes the per-criterion verdict as JSON;
  `landscape export --gate-report FILE` labels every exported assessment `release` or
  `experimental` from it.
- Report format (engine choice): JSON object
  `{"version": 1, "overall": "pass"|"fail", "criteria": {"<criterion_id>": {"release":
  "release"|"experimental", "reasons": ["n<10", ...]}}}`; criteria sorted; `reasons` empty on
  pass (same reason strings as the `gate` lines). Built by `core.eval_thresholds.gate_report`.
- Writing: after the gate lines, atomically (`<FILE>.tmp` then rename), also when the gate fails
  (exit stays 1). `--gate-out` without `--gate` exits 2 before any setup or database read.
- Export: `--gate-report FILE` (optional), read by `core.eval_thresholds.load_gate_report`
  before any output. JSON Lines objects gain `"release"`; CSV gains a trailing `release` column
  (header and rows). A criterion absent from the report is `ungated`. Without the flag JSON and
  CSV output are byte-identical to before.
- Errors: `GateReportError` for a missing/unreadable file, bad JSON, wrong version, bad
  `overall`, unknown release value or wrong types; the message names the file, never content.
  Export exits 2 and writes no output file.
- Hidden vs experimental: this item only labels; no row is dropped. Hiding is a later
  publish/static-site choice (residual).
- Connections: `gate_report` ← `run_eval`; `load_gate_report` ← `run_export`; the `release`
  field's consumer is the later publish/static-site row. Report size is bounded by the
  criteria count; the export stays row-streaming.
- Non-goals: `publish`/static-site command, real gold set (H), threshold tuning (H),
  ARCHITECTURE.md/decisions edits, schema changes, `scores-export`/`attributes-export`/`mosaic`.
