# AD-12: SearXNG implementation of the AD-05 `Search` protocol

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 (Discover › Search channel), §10 (genericity); AD-05
  `adapters/search.py`; D-004 on PR #55 (SearXNG is the decided backend); D-003 (the real SearXNG
  URL is never written anywhere tracked; tests use `http://search.invalid`).
- Objective: new `adapters/searxng.py` exposes `SearxngSearch(base_url: str, *, transport:
  Transport | None = None, timeout: float = 10.0)` that satisfies `Search`. `search(query)` issues
  one GET to `{base_url}/search?q=...&format=json&pageno=1`; language is sent as `language=`;
  `site` is folded into `q` as `site:<host>`. SearXNG has no country parameter but accepts locale
  codes, so language + country is sent as `language=<lang>-<CC>`; a country without a language is
  not sent and cannot be filtered client-side (SearXNG results carry no country), so those results
  have `country=None` (recorded residual). The JSON `results` list maps to `SearchResult` ranked
  1..n with `backend="searxng"` (`content` → snippet; missing/null title or content → `""`),
  stopping at `query.limit` (page 1 only). The injected transport follows `adapters/embedding.py`
  (`HttpResponse` reused, urllib default, GET `Transport` defined locally).
- Errors: transport exception, non-2xx, non-JSON, non-object body, missing/ill-typed `results`, and
  any entry within the limit lacking a string http(s) `url` (or with a non-string title/content)
  raise `SearchError`. Decision: bad entries are **not** skipped and counted; a malformed response
  is treated as a failed call, so nothing is silently dropped. Entries beyond the limit are not
  inspected. Messages never contain the base URL, query text or body; `repr` hides the URL. Invalid
  `base_url` or timeout (non-finite, <= 0, bool, non-number) raises `ValueError`. No `from_env()`
  hook was added.
- Scope / non-goals: `adapters/searxng.py`, `tests/test_searxng_search.py`, this file. No
  pagination, retries, rate limiting, caching, query generation, Discover wiring or live calls in
  tests.
- Connections: **unwired by design**; the Phase 1 Discover row (search channel) is its production
  caller.
- Scale: one response body in memory; at most `query.limit` results returned.
- Acceptance: tests written first and seen failing with `ModuleNotFoundError: No module named
  'adapters.searxng'`; a fake transport records the request URL; tests cover isinstance
  conformance (and mypy via `_conforms()`), query-string encoding (q, format=json, pageno,
  language, site, locale), mapping + ranks, limit truncation, each error path, timeout validation
  and no network (`urlopen` patched to fail).
- Evidence / residuals: round 24/A1, branch `task/ad-12-searxng-search`, base 95737e3. Offline gate:
  `uv run pytest` → 532 passed, 5 skipped (pre-existing, `DM_TEST_DATABASE_URL` unset; PostgreSQL paths not exercised), 130 subtests;
  `uv run ruff check .` passed; `uv run ruff format --check adapters tests/test_searxng_search.py`
  passed; `uv run mypy core adapters` no issues in 22 files. Residuals: never exercised against a
  live SearXNG instance (response shape is per SearXNG's JSON format, unverified live); country
  without language is neither sent nor filtered; JSON format must be enabled on the instance;
  no `SEARXNG_URL` settings hook yet (left to the wiring row).
