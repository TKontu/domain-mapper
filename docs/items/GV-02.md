# GV-02: Shrink-only module reachability ratchet

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: operator governance direction 2026-11-26 (HANDOFF.md standing rulings); AGENTS.md "Connections" rule (a new public symbol names its production caller, or is "unwired by design" with the row that wires it); GV-01 (`scripts/check_import_direction_ratchet.py`) as the pattern.
- Objective: a shrink-only ratchet fails the local gate when a public top-level symbol in `core/`, `adapters/` or `app/` has no production reference and is not on the allowlist, or when an allowlist entry is stale (the symbol is now referenced, or no longer exists).
- Policy: public symbol = module-level `def`, `async def`, `class` or simple-name assignment whose name does not start with `_`, in `core/**/*.py`, `adapters/**/*.py`, `app/**/*.py`. Production reference = any `ast.Name` load or `ast.Attribute` attr equal to the symbol name, or an `import`/`from ... import` naming it, in any production file (those three packages plus `scripts/`) other than the defining module's own definition; references from `tests/` do not count. Names listed in a module's `__all__` count as used only if referenced elsewhere. Entry points named in `pyproject.toml` `[project.scripts]` count as referenced. Allowlist `tests/fixtures/reachability_ratchet.toml`: `"<file>::<name>" = "<reason or row id that wires it>"`, seeded at base with every currently unreferenced symbol and reason `"unwired at seed (GV-02)"`. Name-based matching is deliberately coarse (a same-named symbol elsewhere counts as a caller); record this as a residual.
- Scope / non-goals: new `scripts/check_reachability_ratchet.py` (with `--print` emitting the current unreferenced set as TOML), the fixture, `tests/test_reachability_ratchet.py` (real tree plus synthetic trees: new unreferenced symbol fails, test-only reference fails, stale entry fails, private names ignored, `--print` round-trip), this file, its todo row. No deletion of dead code (later items), no edits to `.agent/config.toml`, `.github/`, docs/decisions.md.
- Acceptance: checker exits 0 on the tree; tests show non-zero exit with a message naming file and symbol; full gate green.
- Connections: checker's production caller is the gate test; unwired by design otherwise.
