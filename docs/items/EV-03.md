# EV-03: eval thresholds file + `landscape eval --gate`

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §7 ("Release gate per layer: thresholds defined in
  `eval/thresholds.yaml` (overridable per scope)"); D-003 (neutral fixtures only). Builds on
  EV-01 (`core/eval_metrics.py`) and EV-02 (`landscape eval`, `run_eval` in `app/cli.py`).
- Objective: `landscape eval --scope S --gate [--thresholds FILE]` additionally checks every
  criterion's metrics against thresholds; after the metric lines it prints, sorted,
  `gate <criterion_id> pass` or `gate <criterion_id> fail <reason>[,<reason>...]` (e.g. `n<10`,
  `accuracy<0.8`, `kappa=none`, `false_strong_rate>0.05`), then `gate overall pass|fail`; exit 1
  if any criterion fails. Without `--gate` output and exit are unchanged.
- Format (engine choice): YAML. `default: {min_n, min_accuracy, min_kappa, max_silent_rate,
  max_false_strong_rate}` plus optional `criteria: {<criterion_id>: {<subset>}}`. Every key is
  optional; `default` must exist in the engine file. An omitted key is no check; bounds are
  inclusive. Engine file `eval/thresholds.yaml` at the repo root holds PROVISIONAL defaults
  (10 / 0.8 / 0.6 / 0.2 / 0.05) for an expert/operator to tune.
- Location: the engine file is found as `Path(app/cli.py).resolve().parent.parent /
  "eval/thresholds.yaml"` (`app.cli.ENGINE_THRESHOLDS`), i.e. relative to the source tree,
  never the CWD.
- Override: `<scope>/eval/thresholds.yaml` (same shape), merged key by key: scope `default`
  over engine `default`; per-criterion keys (engine, then scope) over the merged default. A
  missing scope file means engine only. `--thresholds FILE` replaces the scope path; a missing
  explicit file exits 2.
- Errors: `core.eval_thresholds.ThresholdsError` for bad YAML, unknown key, non-numeric (incl.
  bool) value, rates outside [0,1], kappa outside [-1,1], negative or non-integer `min_n`;
  messages name the file and key, never the value. ThresholdsError or a missing engine file →
  stderr, exit 2 (checked before any database read).
- Gate semantics: `check_gate` excludes `OVERALL`; a `None` metric with a set threshold fails
  (`<metric>=none`); `n < min_n` fails.
- Non-goals: `publish` command / marking criteria experimental in exports (later item), real
  gold set (H), ARCHITECTURE/decisions edits, schema changes, live models.
- Evidence / residuals: PR for round 189/A1. Residual: `publish` wiring pending; thresholds are
  provisional; seen only on tmp_path fixtures.
