# AD-05: `Search` adapter interface

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Adapters).

- Target references: ARCHITECTURE.md §4 (Discover › Search channel: queries = vocabulary terms ×
  language × country), §10 (genericity contract); D-003 (no domain words); `adapters/embedding.py`
  and `adapters/registers.py` (Protocol + frozen-dataclass house style). The search backend is an
  open (D) decision ("Search backend for discovery") and is deliberately not chosen here.
- Objective: `adapters/search.py` defines a `runtime_checkable` `Search` protocol with one method
  `search(query: SearchQuery) -> list[SearchResult]`; frozen `SearchQuery(text, limit=25,
  language, country, site)`; frozen `SearchResult(query, url, title, snippet, rank, backend,
  language, country)`; `SearchError` (a `ValueError`); and `InMemorySearch`, a fake for tests and
  the example scope.
- Query semantics: blank text or a non-positive / non-integer / boolean `limit` raises
  `SearchError` at construction. The fake matches query text as a case-insensitive substring of
  title or snippet; language and country filter by case-insensitive equality; `site` matches the
  URL host or any subdomain. Filters combine with AND. Results are ranked `1..n`.
- Scope: `adapters/search.py`, `tests/test_search_adapter.py`, `docs/items/AD-05.md`.
- Non-goals: real backends, network calls, DB tables, stage wiring, dependency changes.
- Acceptance: tests written first, failed with `ModuleNotFoundError: No module named
  'adapters.search'`. They show protocol conformance (isinstance; mypy via `_conforms()`), limit
  enforcement and rejection of `limit <= 0`, ranks 1..n (also after site filtering), each filter,
  case-insensitivity, empty result, and frozen records.
- Scale / memory bound: `search` returns a materialised list of at most `query.limit` results
  (default 25); the fake stops scanning at the bound and holds its fixture tuple in memory. A real
  backend must push the limit to the source.
- Connections: **unwired by design**. First production caller: the Phase 1 Discover row (search
  channel), which will map results to `candidate(..., channel, query, found_at)`.
- Evidence / residuals: round 12, branch `task/ad-05-search-adapter`, base ce1d177. Gate offline:
  `uv run pytest` → 349 passed, 3 skipped (pre-existing, `DM_TEST_DATABASE_URL` unset), 126
  subtests; `uv run ruff check .` → passed; `uv run ruff format --check adapters/search.py
  tests/test_search_adapter.py` → passed; `uv run mypy core adapters` → no issues in 13 files.
  Residuals: no backend chosen; no pagination, retry, rate limiting, caching or query generation;
  result shape is an engine-side assumption to check against the chosen backend.
