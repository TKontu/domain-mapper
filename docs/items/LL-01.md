# LL-01: local LLM gateway auth

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md LLM adapter section; AD-01 (`adapters/llm.py`); operator
  hard rule 2026-11-27: no secret ever reaches GitHub, logs or repr.
- Objective: the local/vllm/openai backend built by `adapters.llm.build_llm` sends
  `Authorization: Bearer <key>` when `DM_LLM_GATEWAY_API_KEY` is set, and no Authorization header
  when it is unset or blank.
- Scope / non-goals: `core.config.Settings.llm_gateway_api_key` (`repr=False`, blank -> None),
  passed as `api_key=` in `_build_inner`'s local branch; masked in the CLI config display
  (`_SECRET_FIELDS`); placeholder in `.env.example`. No live calls, timeouts, retrieval or network.
- Acceptance: tests with a fake key only: settings load and blank -> None; key absent from repr;
  Bearer header sent with key, none without; CLI display masks it; at DEBUG, a completed and a
  failed call never put the key in log output or `llm_call` rows. Full gate green.
- Residuals: live smoke call against the real gateway not run (follow-up in the LL-01 row).
