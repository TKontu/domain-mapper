# AS-12: `landscape export --format json` of the current assessment view

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 data model (current view is a separate query);
  `core/assessment_store.py` `current_assessments` (AS-11); D-003 (neutral fixtures only).
- Objective: `landscape export --scope S --format json --out PATH [--entity ID] [--criterion C]
  [--rubric-version V]` writes the AS-11 current view as JSON Lines: one object per current
  assessment, keys `id, entity_id, criterion_id, status, confidence, rationale, rubric_version,
  extractor_model, verifier_model, decided_by, route_kind, run_id, created_at` (ISO 8601) and
  `evidence` (list of `{chunk_id, quote, grounded}`), in `current_assessments` order. Rows are
  written one at a time to `PATH.tmp` and renamed to `PATH` on success. Prints
  `exported N assessments to PATH` (N may be 0, exit 0). A format other than `json`, missing
  scope or an unwritable output directory exits 2 and leaves no `PATH`.
- Scope / non-goals: `core/cli.py` (new command and its `run_export` helper),
  `tests/test_cli_export.py`, this file and the AS-12 `todo.md` row. No changes to
  `current_assessments`, schema, migrations, writes, CSV or other formats, ARCHITECTURE.md or
  docs/decisions.md.
- Acceptance: offline pytest failing at base and passing at head — line count and key set,
  evidence nested per row, newer write supersedes older, filters pass through, empty DB writes an
  empty file and `exported 0`, bad format exits 2 with no file, missing scope exits 2. Full gate
  green.
- Evidence / residuals: assignment 69/A1 PR (head SHA and gate counts). Residuals: offline SQLite
  only; `current_assessments` returns a list, so the whole current view is held in memory before
  writing (the file write itself is per row); `--scope` does not narrow rows (no scope column).
