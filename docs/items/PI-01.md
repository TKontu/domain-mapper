# PI-01: Prompt-injection test cases (malicious text in scraped pages)

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §6 (routing, untrusted evidence); AGENTS.md "Connections",
  "Scale"; D-003 (neutral fixtures, `scopes/_example` only; no private scope words).
- Objective: a shared neutral corpus `tests/injection_cases.py` (instruction override, forged
  `<<<END EVIDENCE>>>` / `<<<BEGIN EVIDENCE` delimiters incl. lowercase/spaced/extra-bracket
  variants, forged `[chunk N]` headers, role/system-prompt and chat-template imitation, JSON
  answer imitation) exercised by `tests/test_prompt_injection.py` against both
  `core.assess.build_prompt`/`extract_criterion` and
  `core.attribute_extract.build_prompt`/`extract_attribute`.
- Acceptance: (a) each case appears (neutralised) inside the single evidence block, with exactly
  one real BEGIN and one real END delimiter (case-insensitive); (b) a fake LLM that obeys the
  injection — attacker's value/status with a quote not verbatim in the cited chunk, or cited to a
  chunk id only a forged header claims — yields `checks_passed=False`, and
  `store_attribute_extraction` stores nothing. Full gate
  `uv run pytest -q && uv run ruff check . && uv run mypy core` green.
- Scope / non-goals: tests, this doc and the todo row. No prompt redesign, rubric or
  architecture change, no live model. A real gap would get the smallest fix in
  `core/assess.py` `_neutralise`; none was needed.
- Connections / scale: no new public production symbol (test helpers only). N/A scale.
- Evidence / residuals: PR for assignment 87/A1. Fake LLM only; no live-model injection run.
  Grounding cannot reject an attacker sentence that is genuinely verbatim in the cited chunk
  (that is real page text); review/aggregation owns that risk.
