- Objective: `landscape assess` accepts `--embedding-model TEXT` (default unset). When set, an
  Embedder is built through `_make_embedder(settings, model)` before the run row opens and passed

  Empty/whitespace value → `error: --embedding-model must be non-empty`, exit 2. Unset → the
  keyword-only call is unchanged.
