# GS-02: LAN-only review server

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: operator ruling 2026-11-28 (model: an existing stdlib review server).
- Objective: `python3 -m app.review_server start|stop|status [--root DIR] [--port 8741]` serves
  registered static pages from a root dir to the LAN only (bind to a private address or loopback,
  refuse public binds), accepts JSON submissions per page into `answers.json` (atomic write) and
  appends every submission to `history/`. Stdlib only; pid file for stop/status.
- Scope / non-goals: server and offline tests (loopback, ephemeral port). No page content (GS-03),
  no auth beyond LAN binding, no gold import (GS-04).
- Acceptance: tests for register/serve, submit → answers.json + history entry, unknown page 404,
  oversized/invalid body rejected, public bind refused, start/stop/status; full local gate green.
- Evidence / residuals: to be filled at reconcile.
