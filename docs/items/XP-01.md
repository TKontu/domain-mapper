# XP-01: `scores-export --format csv` for operator spreadsheets

Status and dependencies live in the canonical backlog (`todo.md`, Phase 4 › Exports).

- Target references: ARCHITECTURE.md export/frontend sections; AG-04 (scores-export), AG-03
  (scores object), FE-04 (`layers`). No decision needed: additive output format, default unchanged.
- Objective: `landscape scores-export --scope S --out PATH --format csv` writes one CSV (RFC 4180
  via the `csv` module, header row, UTF-8, `\n` line endings) with one row per screened entity
  carrying the same data as the JSON Lines line. `--format jsonl` (default) is unchanged.
- Scope / non-goals: `app/cli.py` (`scores-export` command, `run_scores_export` and two private
  helpers), `tests/test_cli_scores_export_csv.py`, this file, one `todo.md` row. Non-goals: Parquet
  (new dependency), `export`, `mosaic`, JSON Lines output changes.
- Acceptance: columns `entity_id, segments, layers, rubric_version`, then per rubric topic in rubric
  order `<topic_id>.score, .coverage, .applicable, .scored, .evidenced`; lists joined with `;`;
  `None` -> empty cell; floats via `str(float)` (unrounded). Header written with zero entities;
  skipped count and summary line unchanged. Unknown `--format` exits 2 before setup or any file
  write; same `<out>.tmp` then rename atomicity. Streaming per batch of `SCORES_EXPORT_BATCH`.
- Connections: production caller is the `scores-export` command; consumer is an operator
  spreadsheet (unwired by design beyond that).
- Evidence / residuals: round 121/A1 PR (see todo row). Seen offline only (SQLite tests). Residuals:
  Parquet not done; no run over real assessments; PostgreSQL unexercised.
