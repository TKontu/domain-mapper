Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 stage 7 and §6 routing (extractor = local model);
  `core/retrieve.py` (AS-02); `core/assess.py` (AS-01); `core/cli.py` `run_screen`/`run_search`
  patterns (AB-01 database errors, URL never echoed); D-003 (neutral fixtures only).
- Objective: `landscape assess --scope S --entity ID --criterion C [--n N] [--k K]` runs
  `run_assess`: load the pack, find C in the rubric (unknown → `error: unknown criterion C`,
  exit 2), validate `--n >= 1`, `--k >= --n` (exit 2), build the local extractor via the
  `_make_assess_llm` seam (ValueError/LlmError → exit 2), open one `assess` run row, call
  `retrieve_evidence` then `extract_criterion`, close the run `finished` and print
  `status <s> checks <pass|fail> chunks <n>`, one `quote chunk <id> <grounded|ungrounded>
  <method|-> "<text>"` line per quote, `failure <text>` per failure, `rationale <text>`. Exit 0
  when checks pass; 1 on failed checks or `AssessError`/`LlmError` (stderr
  `error <Name>: <msg>`, run `failed`); database errors print one `database unavailable` line,
  exit 2. `--dry-run` prints the plan.
- Scope / non-goals: `core/cli.py`, `tests/test_cli_assess.py`. No persistence of assessments or
  evidence, no batch over entities/criteria, verifier, cloud escalation, vector leg or reranker.
