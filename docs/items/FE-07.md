# FE-07: hidden-criteria marker on topic scores

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §7 (experimental criteria), §12 Publish; D-003 (neutral
  `scopes/_example`, tmp_path only). Builds on FE-06 (residual "topic scores include hidden
  criteria").
- Objective: under `landscape mosaic --gate-report FILE --hide-experimental`, every topic
  score/coverage cell (mosaic and `--entity-dir` pages) for a topic with at least one hidden
  criterion is marked as including hidden criteria; values are not recomputed.
- Behaviour: such a mosaic `<td class="topic">` gains `data-hidden-criteria="N"` (hidden criteria
  in that topic) and `title="includes N hidden experimental criteria"`, and its text gets an
  escaped " *" suffix; the `score / coverage` header is unchanged. The entity page topic
  `<th class="topic" colspan="6">` gains the same attribute, title and suffix. Topics with no
  hidden criteria, and all output without `--hide-experimental`, are byte-identical to before.
- Scope / non-goals: `app/mosaic.py`, tests. Non-goals: recomputing scores (needs a decision),
  export/eval/CLI flag changes, live models.
- Acceptance: `tests/test_mosaic_hidden_topics.py` fails at base, passes at head; FE-06 tests
  still pass; local gate green.
- Residuals: values still include hidden criteria; seen only on fixtures.
