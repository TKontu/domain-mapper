# DS-03: LLM-recall Discover channel (`landscape recall`)

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 stage 1 (Discover channels: "LLM recall — ask local + cloud LLMs for providers per segment/country — treated as an unverified channel"; output `candidate(name, url, country_hint, segment_hint, channel, query, found_at)`); §6 (single `LLM` protocol, `llm_call` logging); DS-02 (`web-search --save`, `core.candidate_store.record_candidates`); SC-02 (`run_screen`: `build_llm`, run row, budget). No architecture or decision change.
- Objective: `landscape recall --scope S --segment SEG --country CC [--limit N] [--save]` asks the configured LLM (`purpose="recall"`, JSON schema) for providers of one scope segment in one country, prints one `name\turl` line per valid proposal, and with `--save` stores them as `candidate` rows with `channel="llm_recall"`, `segment_hint=SEG`, `country_hint=CC`, `query` = the rendered request label and aware-UTC `found_at`.
- Scope / non-goals: new `core/recall.py` (prompt + schema + `recall_candidates(...) -> list[NewCandidate]`, pure, no DB), the CLI command in `app/cli.py`, `tests/test_recall.py`, this file and its `todo.md` row. Non-goals: confirming recall candidates against another channel or a live site (later Resolve row), cloud-model fan-out, query generation, any change to `candidate` schema or `record_candidates`.
- Acceptance (offline, fake LLM): (a) valid JSON → candidates with channel `llm_recall`, hints set, http(s) URLs only, duplicates by URL dropped, at most `--limit`; (b) invalid JSON / schema violation → `RecallError` naming the field only, CLI exit 1, nothing saved; (c) unknown segment or country not in the scope pack, blank values, limit < 1 → exit 2 before any LLM call; (d) `--save` writes rows and prints `saved N candidates`; without it nothing is written; (e) the LLM call is logged under a `recall` run row like `screen`; (f) the prompt states model output is unverified and must not invent URLs. Full gate: `uv run pytest -q && uv run ruff check . && uv run ruff format --check core adapters tests app && uv run mypy core app`.
- Evidence / residuals: round 180 — `core/recall.py` (`recall_candidates`, `RECALL_SCHEMA`, `RecallError`) and `landscape recall` in `app/cli.py`; `tests/test_recall.py` (24 tests, fake LLM, written first and failing at base 5f0b5d0 with `ModuleNotFoundError: core.recall`) cover (a)-(f). Country validity = union of the scope layers' concrete countries (`*` excluded). No live model run (residual). Unverified channel by design: candidates are hints until another channel or a live website confirms them.
