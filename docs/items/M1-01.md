# M1-01: serial real-source M1 run over the private scope pack

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md pipeline (discover -> resolve -> crawl -> screen -> assess);
  D-003 (public repo neutral), D-004 (SearXNG), D-005 (filesystem raw store), D-007 (LLM-built
  stub pack v0 for this run). Origin: operator ruling 2026-11-28 after the private stub-pack PR
  merged (SP-07).
- Objective: one serial live run with the real `landscape` CLI over the private scope pack named
  by the assignment: `web-search --save` (real SearXNG) -> `resolve --apply` -> `crawl` (entity
  mode, real fetcher, robots respected, the pack's crawl policy) -> `screen --jobs 1` (local
  model) -> `assess` per in-scope entity x applicable criterion; about 20 candidates. Driver:
  `scripts/live_real_m1_run.py` (reuses the LL-01 driver's redaction and step runner; env values
  only in the child environment). All outputs (SQLite DB, raw snapshots, logs, summary, the query
  file) stay in a gitignored run directory.
- Scope / non-goals: the driver, `tests/test_live_real_m1_run.py` (offline), the neutral run
  record `docs/runs/M1-01.md`. No engine change, no rubric edit, no publishing.
- Acceptance: per step command name, exit code, elapsed time; counts of candidates, entities,
  snapshots, screens by status, assessments by status and route, llm_calls ok/error. The run
  record carries only counts, outcomes, failure causes and residuals (no names, domains, URLs or
  scope words). Offline gate green.
- Connections: the driver is a planner/operator tool, unwired by design (like
  `scripts/live_m1_run.py`).
