# IX-03: portable BM25 keyword search over chunks

Status and dependencies live in the canonical backlog (`todo.md`, Phase 1 › Index).

- Target references: ARCHITECTURE.md §6 Index ("BM25 / Postgres full-text in parallel"); CH-03 (`ChunkRow`); CR-01 (snapshot `entity_id`); D-003.
- Objective: `search_chunks(engine, query, *, limit=10, entity_id=None, batch_size=500) -> list[KeywordHit]` ranks chunks by Okapi BM25 (k1=1.2, b=0.75, IDF ln(1+(N-df+0.5)/(df+0.5))), score desc then chunk_id asc; `tokenize` casefolds and splits on `str.isalnum` runs.
- Design: dialect-independent; two keyset passes over `chunk.id` (stats, then scoring) with a heap of size `limit`; memory bounded by one batch. Unwired by design until IX-04 (CLI `landscape search`).
- Evidence: round 50, PR #116 merged at head 37f2f2a (main 5901313). Offline only: ImportError failing first at base; planner gate at head 1078 passed, 5 Postgres skips, ruff/format/mypy clean. Not seen through a production caller; IX-04's CLI run over a crawled DB copy will show it.
- Residuals: O(corpus) scan per query; Postgres tsvector/GIN index later; no stemming/language packs; paging shown by batch-size equivalence only.
