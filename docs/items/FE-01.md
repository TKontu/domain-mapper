# FE-01: static mosaic page from scores and export

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md frontend row (static site, host anywhere, no backend); D-003
  (neutral fixtures only, `scopes/_example`); GV-01/GV-02/GV-03 (CLI composition root in `app/`,
  core imports no adapters). Consumes AG-04 (`scores-export`) and AG-06 (`export` evidence source).
- Objective: `landscape mosaic --scope DIR --scores SCORES.jsonl --export EXPORT.jsonl --out
  PAGE.html` writes one self-contained HTML file: rows = entities from the scores lines, columns =
  rubric criteria grouped under topic headers in rubric order; each topic cell shows the entity's
  topic score / coverage; each criterion cell is coloured and labelled from `status_scale` for the
  current status (empty when none); clicking a cell (`<details>`, no JavaScript) reveals status
  label, confidence, rationale and each evidence quote with url link and fetched_at.
- Scope / non-goals: `app/mosaic.py::render_mosaic(pack, scores_lines, export_lines) -> str`
  (pure); `app/cli.py::run_mosaic` streams the JSONL files and writes `<out>.tmp` then renames.
  Non-goals: entity page, hover tooltips, maps, JS frameworks, CDN assets, network, DB access,
  export/scores-export shape changes, profile weights.
- Acceptance: offline pytest (`tests/test_mosaic.py`) failing at base, passing at head: criteria
  under topics in rubric order and every scored entity listed; assessed cell carries scale
  label/color and evidence quote, url, fetched_at; JSONL text HTML-escaped; unassessed criterion is
  an empty cell; CLI writes atomically and exits 2 on missing input or bad scope; no `http(s)://`
  references except evidence links. Full gate green, both ratchets pass.
- Evidence / residuals: round 106/A1 PR (see todo.md); no browser run (seen offline only); export
  lines folded into a dict keyed (entity_id, criterion_id), O(entities x criteria) memory; a later
  export line for the same key overwrites an earlier one; status colours are passed through as CSS
  colour names (`hatched` mapped to a stripe pattern).
