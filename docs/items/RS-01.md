# RS-01: content-addressed filesystem raw store

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §4 (Crawl & snapshot), §5 (`snapshot` table); CR-01
  `snapshot.sha256`; D-005 on PR #55; D-003 (neutral fixtures).
- Objective: new `adapters/blob_store.py` defines a `runtime_checkable` `BlobStore` protocol
  (`put(data: bytes) -> str` returning lowercase sha256 hex; `get(digest: str) -> bytes`;
  `exists(digest: str) -> bool`), `BlobStoreError` and `BlobNotFound`, `FilesystemBlobStore(root:
  Path)` storing at `root/<d[:2]>/<d[2:4]>/<d>`, and `InMemoryBlobStore`. Writes are atomic (temp
  file in the same dir + `os.replace`) and idempotent (existing digest: no rewrite); `get` verifies
  the sha256 of what it reads and raises `BlobStoreError` on mismatch; a digest that is not 64
  lowercase hex raises `BlobStoreError` (no path traversal). Root resolution helper
  `raw_store_root(env)` reads `RAW_STORE_DIR`, default `data/raw/`, in the new module only.
  Non-goals: MinIO, wiring into `ingest_page`/`record_snapshot`, garbage collection, streaming API,
  config.py changes. Connections: unwired by design; the follow-up row wiring raw bytes into
  `ingest_page` is its production caller. Scale: one blob in memory per call (bounded by the fetcher
  byte cap); streaming is a residual.
- Scope / non-goals: new `adapters/blob_store.py`, new `tests/test_blob_store.py`, this file.
  MinIO, wiring into `ingest_page`/`record_snapshot`, garbage collection, streaming API and
  `core/config.py` changes are out of scope; `todo.md`, `core/`, `.env.example` and `.gitignore`
  are untouched.
- Acceptance: tests written first, failing at base `95737e3` with `ModuleNotFoundError: No module
  named 'adapters.blob_store'`; use `tmp_path`. Cover protocol conformance of both stores,
  round-trip, idempotent put (mtime unchanged), layout path, bad digest rejection including `../`,
  missing → `BlobNotFound`, corrupted file → `BlobStoreError`, no temp files left after put, and
  env default/override. `uv run mypy core adapters` passes.
