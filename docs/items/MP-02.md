# MP-02: market presence evidence linkage

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 data model `market_presence(entity_id, country,
  presence_type, evidence_id)`; MP-01 (`docs/items/MP-01.md`, `core/presence_store.py`);
  `core/chunk_store.py` (`ChunkRow.snapshot_id`); `core/snapshot_store.py`
  (`SnapshotRow.entity_id`); D-003 (neutral fixtures only, `scopes/_example`); GV-01/GV-02/GV-03
  ratchets.
- Objective: a presence row can cite evidence. `record_presence(..., evidence_id=None)` stores
  the chunk id; on an existing (entity_id, country, presence_type) row a NULL evidence_id is
  filled by a non-NULL value and an existing non-NULL value is kept (same id returned).
  `presence_evidence_many(session_or_engine, entity_ids)` reads `(country, type, evidence_id)`
  per entity in one query; `presences_many` keeps its shape.
- CLI: `landscape presence-set ... --evidence CHUNK_ID` (optional) requires the chunk to exist and
  its snapshot's `entity_id` to equal `--entity`; otherwise exits 2 with one line and writes
  nothing. `landscape presences` prints `country type` lines with ` evidence N` appended when set,
  then `layers: ...` unchanged.
- Scope / non-goals: evidence linkage only; no automatic extraction from page text, no LLM, no
  migrations, no Postgres, no scores-export/mosaic changes, no per-type layer weighting.
- Connections / scale: `presence-set --evidence` is the production caller of the evidence path;
  `landscape presences` is the production caller of `presence_evidence_many`. One query per
  call; callers batch <=500 ids (not enforced).
- Acceptance: offline pytest failing at base, passing at head (`tests/test_presence_store.py`,
  `tests/test_presence_cli.py`): record with evidence and read back; NULL then evidence fills
  it; evidence then other evidence keeps the first; `--evidence` of an unknown chunk or of a
  chunk whose snapshot belongs to another entity or none exits 2 writing nothing; `presences`
  prints ` evidence N` only where set; MP-01 / FE-04 / EX-01 tests unchanged and green. Full
  gate green.
- Evidence / residuals: assignment 112/A1; the PR body carries the head SHA and gate counts.
  Residuals: manual linkage only; SQLite only; the stored evidence is not re-checked if a chunk
  is later removed (no foreign key, as for chunk/snapshot).
