# PI-03: Injection corpus covers the verify prompt

Status and dependencies live in the canonical backlog, not duplicated here.

- Origin: PI-01 (docs/items/PI-01.md) and PI-02 (docs/items/PI-02.md) covered the assess,
  attribute extract and screen prompts only; `core.verify.build_verify_prompt` was untested
  against the corpus.
- Target references: ARCHITECTURE.md §6 (untrusted evidence); D-003 (neutral fixtures,
  `scopes/_example` only).
- Objective: the PI-01 corpus covers `core.verify.build_verify_prompt`: injected page text sits
  only inside the one real evidence block, and extraction quotes/rationale echoing injected text
  (including forged delimiters) never produce a real BEGIN/END delimiter outside that block.
- Acceptance: (a) every corpus case in a verify prompt (honest-quote extraction) appears inside
  exactly one real BEGIN and one real END delimiter (case-insensitive); (b) with corpus text in
  the extraction's quote and rationale the prompt still has exactly one real BEGIN and END;
  (c) existing verify tests pass; (d) gate
  `uv run pytest -q && uv run ruff check . && uv run mypy core app` green.
- Non-goals: verify schema, routing, the CLI, other prompts, rubric or architecture changes,
  live model.
- Connections / scale: no new public symbol; test-only if no gap is found.
