# MP-01: market presence store and layer membership

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 data model `market_presence(entity_id, country,
  presence_type, evidence_id)` and the Layer row ("membership derived from market presence");
  `core/scope_pack.py` (`Layer.countries`); `core/entity_store.py` (`Entity`);
  `core/attribute_store.py` (store pattern on `core.runs.Base`); D-003 (neutral fixtures only,
  `scopes/_example`); GV-01/GV-02/GV-03 ratchets.
- Objective: `core/presence_store.py` stores `market_presence(id, entity_id, country,
  presence_type, evidence_id)` rows; `presence_type` is one of `hq|site|field_service|sales|remote`
  and country an uppercase ISO-3166 alpha-2 code (`ValueError` otherwise). `record_presence` is
  idempotent on (entity_id, country, presence_type); `presences_many` reads many entities in one
  query; pure `layer_ids_for(layers, countries)` returns the scope layers (in order) whose
  countries contain any given country, or `"*"` when countries is non-empty.
- CLI: `landscape presence-set --scope S --entity ID --country CC --type T` records one row and
  commits; `landscape presences --scope S --entity ID` prints sorted `country type` lines then
  `layers: a, b`. Invalid type/country or an entity not in the scope exits 2 with one line and
  writes nothing.
- Scope / non-goals: no mosaic `--layer` filter (next item), no layers in scores-export, no
  presence extraction from crawled pages, no evidence linkage (evidence_id NULL from the CLI), no
  migrations, no Postgres run, no per-type weighting of membership.
- Connections / scale: the two CLI commands are the production callers; `layer_ids_for`'s next
  consumer is mosaic `--layer`. `presences_many` is one query per call; callers batch <=500 ids
  (not enforced).
- Acceptance: offline pytest failing at base, passing at head (`tests/test_presence_store.py`,
  `tests/test_presence_cli.py`): record/read back and idempotent duplicate; invalid type,
  lowercase or 3-letter country raise / exit 2 writing nothing; `presences_many` multi-entity, one
  query, missing entity absent; `layer_ids_for` on the example layers ([XA] -> home, region,
  global; [XB] -> region, global; [ZZ] -> global; [] -> []); `presences` output and unknown entity
  exit 2. Full gate green.
- Evidence / residuals: assignment 109/A1; the PR body carries the head SHA and gate counts.
  Residuals: SQLite only; manual presence only; any presence type counts toward a layer; the
  <=500-id batch bound is the callers', not enforced.
