- Architecture sections / approved decisions: ARCHITECTURE.md §4 stage 4 Crawl & snapshot ("Per-entity crawl policy from the scope pack: max pages, priority URL patterns"); D-003 (tests and examples use `example.com`/`.invalid` hosts and neutral words only); D-005 raw store.
- Objective: the scope pack gains an optional `crawl` section in `scope.yaml` — `max_pages` (int, 1..50, default 1) and `priority_paths` (list of absolute paths starting with `/`, default empty, no scheme/host/query/fragment, duplicates rejected). Entity-driven `landscape crawl --scope <dir>` fetches, per entity in id order, the homepage `https://<primary_domain>/` then each priority path in listed order, stopping at `max_pages` URLs per entity; every URL goes through the existing robots/rate-limit/ingest path with that entity's id. With no `crawl` section behaviour is exactly CR-04 (homepage only). `--limit` still counts entities, not pages. `--url` path unchanged.
- In scope: `core/scope_pack.py` (an optional `CrawlPolicy` model on the scope model, validated), `core/cli.py` entity crawl target generation, `scopes/_example/scope.yaml` (add a small illustrative `crawl` section, e.g. max_pages 3 and `/about`, `/services`), the JSON-schema export if it is generated from the models (regenerate any tracked output), tests. Non-goals: link extraction/discovery from fetched pages, glob/regex URL patterns, PDFs, languages, re-crawl skipping, per-layer policy, migrations.
- Premises: (1) `_homepage` in `core/cli.py` returns the single URL per entity: `grep -n "_homepage" core/cli.py`; (2) the scope model has no crawl field yet: `grep -n "crawl" core/scope_pack.py` is empty; (3) `landscape validate --scope scopes/_example` passes on base.
- Expected files: `core/scope_pack.py`, `core/cli.py` (entity crawl only), `scopes/_example/scope.yaml`, tests, any generated schema file. Do not touch ARCHITECTURE.md, docs/decisions.md, todo.md, .agent/, .claude/, scripts/.
- Resources / artifacts: none; offline SQLite and fakes only (the existing crawl CLI test seams). No network, no live DB, no paid APIs.
- Acceptance: offline tests show — no `crawl` section → homepage only per entity (existing CR-04 tests pass unchanged); `max_pages: 3, priority_paths: [/a, /b, /c]` → per entity exactly homepage, /a, /b in that order with the entity's id on each snapshot; robots disallow on one path prints `skipped <url> robots` and the rest continue; `--limit 1` with 2 entities fetches pages of only the first; invalid policies (max_pages 0 or 51, path without leading `/`, path with `?` or `#` or `//host`, duplicate path) fail `load_scope_pack` with a ScopePackError naming the field; `uv run landscape validate --scope scopes/_example` still exits 0.
