# LB-01: per-run LLM budget cap

Status and dependencies live in the canonical backlog (`todo.md`, Phase 1 › Screen).

- Target references: ARCHITECTURE.md §6 model routing ("Per-run budgets for cloud tokens"); SC-02 residual (`llm_budget_usd` loaded but unenforced); AD-01 (`build_llm`); D-003.
- Objective: an LLM built for a run refuses further calls once the run's accumulated cost reaches `DM_LLM_BUDGET_USD`, and `landscape screen` stops cleanly when it does.
- Design: `adapters.llm.BudgetedLLM` wraps an `LLM`, sums `LlmResult.cost`; before a call, `spent > 0 and spent >= budget_usd` raises `LlmBudgetExceeded` (amounts only, no prompt text) without calling the inner model. Zero-cost calls are never refused. `build_llm(..., budget_usd=)` wraps when given; `landscape screen` passes `settings.llm_budget_usd` (one budget per invocation). On `LlmBudgetExceeded` the screen loop prints `error <id> LlmBudgetExceeded: ...`, stops, leaves that and later entities `unscreened`, exits 1.
- Connections / scale: production caller is `landscape screen` via `_make_screen_llm`; O(1) state per run.
