# LW-01: Link private scope checkouts into a lane worktree

Status and dependencies live in the canonical backlog (`todo.md`, Phase 0 › Repo & infra).

- Target references: D-003 (private scopes live under gitignored `scopes/<name>/`); `.gitignore` `scopes/*` rule; `.agent/supervisor.md` "Live work" (lane worktrees are sibling paths such as `/work/wt-<lane>`).
- Objective: `python3 scripts/link_scopes.py --worktree <path> [--source <main checkout>] [--dry-run] [--unlink]` symlinks every private scope directory of the source checkout (each `scopes/<name>/` that is a directory, excluding `_example` and anything git tracks) into `<path>/scopes/<name>`, so a lane reads private packs without copying them. `--source` defaults to the main checkout of the worktree's repository (`git rev-parse --git-common-dir`).
- Output: one line per scope name — `linked`, `ok` (correct link already present, left alone), `conflict` (non-link or foreign link present; untouched, exit 1, message on stderr), `would link` under `--dry-run`; with `--unlink`: `unlinked` / `would unlink` for links this tool would create, `kept (not our link)` otherwise, `absent` when nothing is there.
- Usage (planner, when provisioning a lane worktree): `python3 scripts/link_scopes.py --worktree /work/wt-<lane>`; before removing the worktree, `python3 scripts/link_scopes.py --worktree /work/wt-<lane> --unlink`.
- Scope / non-goals: `scripts/link_scopes.py` (stdlib only), `tests/test_link_scopes.py` (unittest, hermetic tmp git repos with invented scope names), this file, the `todo.md` row. Non-goals: `lanes.py` changes, copying files, real scope content, `.agent/*`, `.claude/*`.
- Acceptance: `python3 -m unittest tests.test_link_scopes` — links only untracked scope dirs; rerun idempotent (same inode); refuses non-link and foreign link; dry run creates nothing; `--unlink` removes only own links (and its dry run); default source resolves from a real `git worktree`. Tests failed before the script existed (module not found).
- Connections: new CLI script; production caller is the planner provisioning lane worktrees (manual invocation; not wired into `lanes.py`, by design of this item). Scale: N/A (a handful of directories).
- Evidence / residuals: round 9, assignment A2, PR #25 merged (head d2b49b3); seen on a fresh worktree of main: 1 linked, status clean, unlink clean. Residuals: (1) a non-git `--worktree` gives a traceback; (2) a scope directory that is itself a symlink in the source is skipped; (3) a link made with `--source X` is reported `kept (not our link)` by `--unlink` run with a different source.
