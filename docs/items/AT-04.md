# AT-04: batched attributes export query

Status and dependencies live in the canonical backlog, not duplicated here.

- Target references: ARCHITECTURE.md §5 (`attribute_value`), §6 exports; AGENTS.md "Scale";
  `core/attribute_store.py` (`current_attribute_values`, AT-01); `core/cli.py`
  (`run_attributes_export`, AT-03); D-003 (neutral fixtures only, `scopes/_example`).
- Objective: add `current_attribute_values_many(session, entity_ids) -> dict[int, dict[str, Any]]`
  to `core/attribute_store.py`: one query for the given ids returning, per entity with values, the
  latest (highest id) decoded value per attribute id; entities without values are absent; empty
  input returns `{}` without querying. `run_attributes_export` collects entity ids from
  `iter_entities` in batches of at most 500 (`ATTRIBUTES_EXPORT_BATCH`) and calls it once per
  batch, one Session per batch. Output bytes, ordering, skip counting, atomic write and error
  behaviour stay identical to AT-03.
- Scope / non-goals: attributes export only; `current_attribute_values` stays for other callers.
  No change to `scores-export` (its N+1 stays) or other commands; no schema change. Files:
  `core/attribute_store.py`, `core/cli.py`, `tests/test_attribute_store.py`,
  `tests/test_cli_attributes_export.py`, this file and the AT-04 `todo.md` row.
- Connections / scale: production caller of `current_attribute_values_many` is
  `run_attributes_export`; memory bounded to one batch (≤500 entities' current values); one
  read-only query per batch with an `IN` list of ≤500 ids.
- Acceptance: offline pytest failing at base, passing at head — over three entities (two with
  several versions, one without) the batched call returns the latest value per attribute for the
  two, matching `current_attribute_values`, and omits the third; empty input → `{}` with no
  statement executed; an export with batch size 2 over 5 entities yields the same lines and
  issues one values call per batch. Existing AT-03 export tests pass unchanged. Full gate green.
- Evidence / residuals: assignment 78/A1; the PR body carries the head SHA and gate counts.
  Residuals: SQLite only, the PostgreSQL path is unexercised; `scores-export` N+1 remains.
